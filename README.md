## Hey, I'm Piyush 👋

I'm a product designer based in Bengaluru. I like taking complex products and
making them feel simple, without hiding the details people rely on.

### What I work on

- AI products, and how people and AI work together in them
- B2B SaaS: dashboards, data-heavy workflows and admin tools
- Design systems, from Figma all the way to coded components
- Websites, designed and built end to end

### How I work

More and more, I design in code. I prototype ideas in Claude Code to see how
they actually behave, build components that match the design exactly, and ship
the things I design. I care about the details most people skip: the interaction
that feels obvious, the component that holds up in every state, the motion that
earns its milliseconds.
